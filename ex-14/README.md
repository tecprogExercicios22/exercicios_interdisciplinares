### Exercicio 14

__Fazer um programa que:__
* __Receba o nome, o código e as duas notas bimestrais de 3 alunos para uma determinada matéria.__
* __Salve estes dados em um arquivo. Os dados devem ser salvos registro a registro, obedecendo o seguinte formato:__
__1. número inteiro contendo o tamanho em char do nome do aluno.__  
__2. sequência de chars correspondente à string que contém o nome do aluno.__  
__3. duas notas na forma de números inteiros.__  
__Fazer um programa para:__
* __ler os dados contidos no arquivo gerado pelo programa anterior__
* __calcular e mostrar: quais alunos foram aprovados, quais foram para exame, quais foram reprovados e a média da turma.__
